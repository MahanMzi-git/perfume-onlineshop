# Landing background

The selected default is the owner-supplied terracotta texture, source 654288652156944534.jpg. The original 1472x736 JPEG (153645 bytes) is preserved at public/images/hero/landing-terracotta.jpg. Its native landscape orientation uses a cover crop with no rotation or stretching. The same approved cream overlays preserve text readability on desktop, phone and portrait tablet. Motion-control colour changes keep the pause/play icon visible on the darker part of the photograph.

The normal home route uses this background without preview parameters. Temporary comparison selectors and rejected study assets are excluded from the shipped version; local reference files remain in ignored preview/hero-background-archive. Replace the single JPEG asset for a future higher-resolution landscape photograph. Text, bottle orbit, centring correction and podium scenes are preserved.
