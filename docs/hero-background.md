# Landing background

The owner selected image 1 (Where the light lingers.jpg) as a temporary default until a higher-resolution photo is found. It is active on the normal home route, without preview parameters. The original 736x1106 JPEG (177369 bytes) is preserved at public/images/hero/landing-wall.jpg and rendered with a 90-degree rotation and cover crop, without stretching. CSS in src/styles/hero-background.css keeps the approved desktop/mobile/tablet readability overlays. Text, orbit geometry, bottle motion and pause behavior are unchanged.

For a higher-resolution replacement, replace the single local JPEG asset. A replacement that is already landscape will also require removing the CSS rotation. The photograph is owner-supplied; this phase does not verify external licensing. Rejected background studies remain in ignored preview/hero-background-archive rather than public assets.
